# Rob mentorship preview

This branch is a standalone demonstration of the portal with example accounts. Open the app, choose Student view or Rob's view, then Sign in. Sign out to switch roles. The demo does not use live Supabase credentials, submit live student records, or send email. Onboarding progress and student sample uploads are local to the viewer's browser. Rob's draft and published states are simulated within the review page.

The private lesson videos are not included in this public GitHub branch. Thumbnails, supporting copy and downloads are present. Real recordings remain in the existing private storage and the local review copy. Welcome and stems recordings are still outstanding. The Calendly link remains real, so do not confirm a booking unless intended.

This preview branch is not intended to replace or merge wholesale into the main production branch. It retains the latest main source, but uses a separate demo entry and a blocked live-service client for the mentorship. Production-ready changes remain in portal-readiness locally.
